# VoxLyra v1.16.0

## Импорт графических произведений

- Сквозной тест массового импорта расширен до 50 комиксов/манги/манхвы.
- Для внешних произведений обязательны проверяемый `source`, `LICENSE.txt` и `SOURCES.txt`.
- Creative Commons принимается только как CC0, CC BY или CC BY-SA.
- CC BY-NC, CC BY-ND и CC BY-NC-SA отклоняются до записи в базу.
- Для разрешения автора требуется `permission_reference`.
- Доказательства прав сохраняются в постоянном каталоге импортированного произведения.
- Исправлено раскрытие локальных машинных путей в именах страниц 7Z.

## Покупки и доступ

- Покупка отдельной главы больше не открывает другие главы книги или весь том.
- Покупка главы не считается покупкой графического тома.
- Режим `chapters` поддерживает продажу отдельных глав при нулевой цене всей книги.
- Для отменённого счёта выводится точная ошибка о невозможности оплаты.

## Проверка проекта

- QA-скрипты массового импорта запускаются напрямую из корня репозитория.
- `pytest` собирает тесты только из настоящего каталога `tests/`.
- Добавлен безопасный `.env.example` без секретов.
