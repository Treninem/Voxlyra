# VoxLyra

VoxLyra — единая платформа для книг, комиксов/манги/манхвы/вебтунов и аудиокниг с Telegram-ботом, Telegram Mini App, VK Mini App, публикацией, модерацией и общей библиотекой.

## Текущая разработка — v1.16.0

Основная реализация GitHub-импорта объединена с `main` (merge `fb35c369646a466a6ab565625a1fc22982bd9b4c`). Дальнейшие исправления по этой задаче вносятся сразу в `main`.

GitHub используется только как источник. После проверки пакет передаётся существующему импортёру VoxLyra и использует существующие БД, хранилище, читалку, публикацию и пользовательские связи.

Источник по умолчанию: `Treninem/bookvoxlyra`. Репозиторий, ветка и корневой путь настраиваются через env.

### Уже в main

- проверка репозитория, обнаружение пакетов и пагинация;

- защита от небезопасных путей;
- потоковая загрузка только выбранного пакета без clone репозитория;
- ограничения временного диска и размера пакета;
- гарантированная очистка временных файлов;
- импорт книг и комиксов через существующий `import_library_zip`;
- история с package/version/commit SHA/status/размером/VoxLyra ID/ошибкой;
- идемпотентность успешно импортированного package/version/commit;
- обнаружение обновлений без автоматической перезаписи;
- массовый импорт новых книг и комиксов;
- повтор неудачных импортов;
- аудиокниги пока намеренно исключены из массового GitHub-импорта;
- выполнена дополнительная чистка корня репозитория: удалены устаревшие `CHANGED_FILES_V1_11_8..12`, `FILE_INVENTORY_V1_11_4..12`, старые `STATUS`, `RELEASE_CHECK`, `FINAL_TEST_REPORT`, `FINAL_RELEASE` и старый `UPDATE_INFO_v1.14.0.36`.

Подробный рабочий статус: `docs/GITHUB_IMPORT_V1_16_0_PROGRESS.md`.

## Архитектурные правила

- Не переносить текущую SQLite БД с Bothost в рамках v1.16.0.
- Не переносить существующую библиотеку.
- Не создавать отдельное постоянное хранилище для GitHub-контента.
- Не заменять существующие способы импорта EPUB/FB2/TXT/PDF/CBZ/CBR/7Z/изображений и массовый импорт.
- Не хранить GitHub token в коде, UI, логах или traceback.
- Telegram и VK используют общую библиотеку, но платформенную оплату: Telegram Stars в Telegram и VK Votes в VK.
- Публикация произведения использует платформенную ссылку: Telegram Mini App для Telegram и VK Mini App для VK.

## Основные каталоги

- `app/` — backend, Telegram/VK, сервисы, БД и бизнес-логика.
- `static/`, `templates/` — Mini App/web UI.
- `tests/` — автоматические тесты.
- `scripts/` — эксплуатационные и проверочные скрипты.
- `docs/` — актуальная техническая документация.
- `data/` — постоянные runtime-данные; реальные пользовательские данные не должны коммититься.
- `storage/` — временные/runtime-ресурсы в зависимости от конфигурации.

## GitHub Import env

```env
GITHUB_IMPORT_ENABLED=false
GITHUB_IMPORT_REPOSITORY=Treninem/bookvoxlyra
GITHUB_IMPORT_BRANCH=main
GITHUB_IMPORT_ROOT=
GITHUB_IMPORT_TOKEN=
GITHUB_IMPORT_TEMP_ROOT=storage/github_import
GITHUB_IMPORT_MAX_PACKAGE_MB=2048
GITHUB_IMPORT_MIN_FREE_DISK_MB=256
GITHUB_IMPORT_PAGE_SIZE=50
```

Для публичного репозитория токен может не требоваться. Для приватного используется минимально необходимый read-only token через переменные окружения.

## Разработка и проверка

Каждый дальнейший рабочий проход по текущей задаче сопровождается обновлением README и проверкой фактического состояния `main`. Отсутствие красного CI само по себе не считается подтверждением готовности.

## Чистота репозитория

Репозиторий очищается только от файлов, которые не участвуют в runtime/deploy/tests/legal. Runtime-код, миграции, необходимые инструкции, тесты, юридические документы и актуальная эксплуатационная документация сохраняются.
