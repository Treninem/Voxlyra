# VoxLyra v1.15.7 — нативная сессия VK

## Исправлено

- Кнопки сообщества запускают `open_app`, а не внешний `open_link`.
- VK передаёт подписанные `vk_*` параметры, поэтому читалка, TTS, покупки и прогресс не требуют Telegram.
- При переходах между каталогом, книгой, главой, аудио и настройками VK-сессия сохраняется.
- Старый внешний URL предлагает вернуться во VK вместо требования открыть Telegram.
- Ошибка входа больше не скрывается общим сообщением: интерфейс показывает отсутствующую ENV-переменную.
- Поддерживается совместимое имя защищённого ключа `VK_SECURE_KEY`.

## Обязательные ENV

```text
VK_ENABLED=true
VK_APP_ID=54713417
VK_APP_SECRET=ЗАЩИЩЕННЫЙ_КЛЮЧ_ИЗ_КАБИНЕТА_VK
VK_GROUP_ID=240755410
VK_OWNER_IDS=224402322
```

`VK_APP_SECRET` нельзя заменять сервисным ключом или токеном сообщества. После изменения ENV обязательно выполнить Redeploy.

## Проверка

1. Удалить старое сообщение бота с внешними ссылками либо просто написать сообществу ещё раз.
2. Нажать новую кнопку «Книги» — приложение должно открыться внутри VK.
3. Открыть бесплатную главу, запустить озвучивание, перейти в следующую главу.
4. В Network запрос `/api/me` должен получить `200`, а не `401`.
