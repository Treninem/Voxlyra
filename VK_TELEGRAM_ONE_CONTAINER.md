# VoxLyra — Telegram + VK в одном контейнере

## Архитектура

Один GitHub-репозиторий и один процесс Bothost одновременно запускают:

- FastAPI/Mini App на одном HTTPS-домене;
- Telegram polling;
- VK Community Long Poll;
- одну SQLite-базу и одно постоянное хранилище `data/`.

Второй контейнер для VK не нужен. Не запускайте второй экземпляр с той же SQLite-базой и теми же polling-токенами.

## Синхронизация

Каталог книг, главы, аудио, комиксы и публичные данные общие автоматически: Telegram и VK обращаются к одной базе.

Личная библиотека, прогресс, покупки, награды и авторский кабинет синхронизируются после однократной привязки аккаунтов. В «Настройки → Telegram + VK» создайте код на одной платформе и введите его на второй. После этого обе внешние учётные записи разрешаются в один внутренний `users.id`.

## VK платежи

Цифровой контент в VK покупается через нативное окно `VKWebAppShowOrderBox` за голоса. Цена формируется сервером и повторно проверяется в callback, клиент не может подменить её.

Укажите в настройках платежей VK callback:

`<WEBAPP_URL>/api/vk/payments/callback`

Переменные окружения:

```env
VK_ENABLED=true
VK_APP_ID=
VK_APP_SECRET=
VK_SERVICE_TOKEN=
VK_GROUP_ID=
VK_GROUP_TOKEN=
VK_OWNER_IDS=
VK_API_VERSION=5.199

# Секрет для проверки платежных callback. Если пусто, код использует VK_APP_SECRET.
VK_PAYMENT_SECRET=

# Пересчёт существующей базовой цены VoxLyra в голоса VK.
# 1.0 = одна базовая единица цены -> один голос.
VK_VOTES_PER_STAR=1.0
VK_PAYMENT_TEST_MODE=false
```

Telegram Stars продолжают работать только в Telegram. В VK та же покупка открывается через голоса и выдаёт доступ в ту же внутреннюю учётную запись VoxLyra.
