## Панель приложения VK

На приложенном снимке красными отмечены две обязательные незаполненные настройки: состояние «Включено» и URL запуска. Установить:

- состояние приложения: **Включено**;
- URL запуска / URL разработки: `https://voxlyra.bothost.tech/`;
- домен приложения: `voxlyra.bothost.tech`;
- минимум один скриншот для последующей модерации.

Пока приложение непроверенное, оно доступно только владельцу, администраторам и тестовой группе. Это не ошибка контейнера.

## Сообщество VK

- Сообщения сообщества: включены.
- Long Poll API: включён, версия `5.199`.
- Событие `message_new`: включено.
- Ключ должен быть создан именно в сообществе `club240755410` с правом сообщений.

После Redeploy отправить сообществу любое сообщение. Бот должен вернуть постоянную клавиатуру «Читать / Слушать / Комиксы / Новинки / Моя библиотека / Моё / Автору».

VK Bridge хранится локально в сборке; доступ к внешнему CDN для запуска не требуется.

## Привязка уже существующих профилей

Если Telegram и VK ранее создали разные профили, после ввода кода показывается сравнение и выбор: объединить всё, оставить Telegram или оставить VK. Решение выполняется одной SQLite-транзакцией, код одноразовый, а событие объединения сохраняется для восстановления и аудита.

## Безопасность

Все ключи, ранее отправленные в чат, скомпрометированы. Их нужно отозвать и создать заново. В ZIP и Git секреты не включены.
