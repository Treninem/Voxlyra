# VoxLyra v1.15.6 — стабильная публикация и импорт комиксов

## Исправлено

- Владелец может опубликовать уже импортированный комикс из статуса `draft`.
- Карточка управления показывает тип произведения, число графических глав и страниц.
- Аудит массового пакета проверяет графику, а не требует текст книги.
- Публикация пакета переводит графические главы в `published`.
- Один PDF/CBZ/ZIP/CBR/RAR/7Z/EPUB или набор изображений можно автоматически разделить на главы и тома.
- Структура `Том N/Глава N/страницы` имеет приоритет; плоский файл делится по заданным безопасным лимитам.
- При частичной ошибке автоматического импорта уже созданные главы откатываются.

## После Redeploy

1. Открыть `Управление → Управление книгами`.
2. Найти старый черновик комикса по ID и нажать «Опубликовать комикс».
3. Проверить карточку в разделе «Комиксы» и открытие первой страницы.
4. Для нового импорта оставить включённым «Автоматически разделить один файл».
